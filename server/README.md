# Customer Success server candidates

Private preparation package on codex/wave2-20261031. No hosted endpoint, connection, domain token, submission or deployment is created. The version mirrors the existing family plugin and no existing version is changed.

Run npm ci, npm run build and npm test. npm start exposes local stdio for an owner-authorized host. Tests use in-memory MCP and a simulated DOM. Browser and real-host tests remain NOT_TESTED.

Tools compute evidence-labelled results in server code. Example scoring choices are explicit. No customer fact is inferred from a name. Methods and reference hashes, candidate bytes and scope limits are in wave2. The server package contains no skill files. UI font licences are embedded in the local resource.
